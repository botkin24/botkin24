# Максим Боткин | Data Analyst

## О себе
Аналитик данных с практическим опытом оптимизации бизнес-показателей и работы со сложными массивами данных (1 млн+ строк). Специализируюсь на проверке коммерческих гипотез, статистическом анализе, сегментации аудитории и построении сквозной отчетности. 

Имею опыт как в продуктовой/маркетинговой аналитике (исследования рынков, когортный анализ, стат-тесты), так и в решении задач Data Science. В проектах всегда ориентируюсь на измеримую бизнес-ценность: помогаю находить точки роста, оптимизировать маржинальность и автоматизировать рутинные процессы.

## 🛠 Технологии и инструменты
**Языки программирования:** Python, SQL
**Аналитика:** Pandas, NumPy, SciPy, Matplotlib, Seaborn, Statsmodels
**Визуализация:** Power BI, Tableau, DataLens
**Базы данных:** PostgreSQL, MySQL
**Инструменты:** Git, Jupyter Notebook, Excel
